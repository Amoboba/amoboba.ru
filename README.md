# amoboba.ru

Сайт **Amoboba**. Статическая страница без сборки и зависимостей —
открывается как обычный `index.html`.

## Структура

```
index.html              разметка страницы
assets/
  css/style.css         вся стилизация, включая анимации секций
  js/main.js            интерактив: шапка, реавилы, canvas-эффекты
  img/                  логотипы проектов и скриншот «Каталожки»
  favicon.svg           марка Amoboba
assets/components/
  amoboba-footer.js     переносимый шаблон высокого подвала Amoboba
footer-template.html    пример подключения подвала на другом сайте
.github/workflows/      публикация на GitHub Pages
```

## Секции

| Якорь             | Проект        | Визуальный приём                                   |
|-------------------|---------------|----------------------------------------------------|
| `#about`          | —             | заголовок, проявляющийся по словам                 |
| `#products`       | —             | сетка логотипов со светом за курсором              |
| `#katalozhka`     | Каталожка     | liquid glass + параллакс скриншота                 |
| `#investconnect`  | InvestConnect | рекламная сцена Material Expressive и карточка портфеля |

Первый экран — асимметричная обложка Amoboba с крупной типографикой,
анимированным фирменным знаком и переходом к сетке проектов.

## Производительность и доступность

- Тяжёлые `canvas`-анимации крутятся только пока секция в кадре
  (`IntersectionObserver`), остальное время `requestAnimationFrame` отменён.
- Эффекты, завязанные на курсор, включаются только при `hover: hover`
  и `pointer: fine` — на тач-устройствах не тратят кадры.
- `prefers-reduced-motion: reduce` выключает анимации и заставку целиком,
  контент сразу виден.
- Картинки вынесены в файлы и грузятся с `loading="lazy"`.

## Локальный запуск

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Публикация

Workflow `.github/workflows/pages.yml` публикует содержимое репозитория на
GitHub Pages при пуше в `main`. Чтобы он заработал, в настройках репозитория
нужно включить **Settings → Pages → Source: GitHub Actions**. Свой домен
(`amoboba.ru`) добавляется там же, в разделе Custom domain.
